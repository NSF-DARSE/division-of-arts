Information on Case Study
1.	Area of focus of the case study: Artificial intelligence-assisted web scraping and event aggregation for arts and culture calendar management in the public sector. Specifically, this case study focuses on building an intelligent, multi-source event discovery pipeline that automatically surfaces relevant arts and culture events occurring in the State of Delaware and compares them against an existing public-facing events calendar to eliminate duplication. The output would be a list that could be imported into DelawareScene.com through a bulk import tool, or done via a human.
2.	Provide a short abstract about the case study (100 words): The Delaware Division of the Arts (DDOA) operates DelawareScene.com, a statewide arts and culture events calendar intended to serve as a comprehensive public resource. Keeping the calendar current is a labor-intensive, manual process that depends on the Division’s grantee organizations to submit their events as announced. This case study challenges participants to design and prototype an AI-powered event scraping system capable of discovering arts and culture events from four distinct source categories: (1) DDOA-funded grantee websites, (2) non-grantee Delaware venues and presenters, (3) public library programming (such as literature, speakers, and arts), and (4) government-sponsored festivals and events. The system should intelligently filter for relevance, normalize event data into a consistent schema, and cross-reference results against the live DelawareScene.com calendar, returning only net-new events not yet listed. A successful prototype would dramatically reduce staff time spent on calendar curation while increasing the volume and diversity of events surfaced for Delaware audiences.
3.	Three clear, deliverable goals we want to achieve. 

Goal 1: Build a functional multi-source event scraper
Develop a working prototype that can crawl and extract event data from at least the first two of the four source tiers below. Each tier represents a distinct scraping challenge:
    Tier 1 — DDOA Grantee Websites: Scrape event listings from a provided list of ~60+ grantee organization websites. These sites vary widely in structure (WordPress, Squarespace, custom CMS, etc.).
    Tier 2 — Non-Grantee Delaware Arts & Culture Events: Identify and extract events from arts venues, galleries, theaters, and presenters operating within Delaware but not receiving DDOA grant funding. This tier requires broader discovery logic, potentially using geographic filtering, keyword matching, or known venue registries.
    Tier 3 — Delaware Public Library Events: Scrape event listings from public library systems across the state, applying filters to surface programs relevant to arts and culture audiences: author talks, art classes, literary events, speaker series, film screenings, and similar programming. Not all library events are in scope (e.g., story time, job fairs).
    Tier 4 — Government & Public Festival Events: Identify arts-relevant events and festivals hosted by Delaware state agencies, county governments, municipalities, and public entities (e.g., state fair, arts in the park programs, cultural festivals sponsored by the City of Wilmington or Town of Lewes).

    Event category / discipline (can provide an existing list of categories used)
    URL / source link for more information
    URL / source link to buy tickets
    Phone number for the public to call for questions or purchases
    Description or summary
    Admission cost (free / ticketed )

Goal 3: Implement a deduplication check against DelawareScene.com
Build a cross-reference module that compares the scraper’s output against the current live listings on DelawareScene.com (or a provided export of existing calendar data), flagging or suppressing any events already listed. The final output should contain only net-new events not yet appearing on the calendar - ready for staff review and import.
